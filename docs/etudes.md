# Études et choix techniques

## Design : Style Requin
Nous avons choisi un design inspiré du requin pour plusieurs raisons :
- L'idée nous semblait originale et visuellement marquante face aux 
  autres groupes
- La conception restait réalisable techniquement avec nos compétences 
  en modélisation 3D
- Le casque et le body requin s'intégraient bien sur la structure 
  de base du robot sans nécessiter de modifications majeures

## Bras articulés avec pelle
Nous avons opté pour des bras reliés par une pelle dans un objectif 
purement offensif pour les Ottolympiades :
- La pelle permet d'avoir une grande surface de contact pour 
  percuter les robots adverses
- L'objectif est de déséquilibrer et renverser les autres robots 
  lors des épreuves de combat
- Les bras sont articulés pour pouvoir se lever et frapper au 
  bon moment

## Contrôle du robot
Nous avons choisi l'application RemoteXY pour contrôler notre robot 
en Bluetooth, ce qui nous permet de déclencher les attaques et 
les déplacements en temps réel pendant les épreuves.
