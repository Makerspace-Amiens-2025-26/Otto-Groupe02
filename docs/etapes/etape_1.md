# Impression 3D

## Matériel nécessaire
- Imprimante 3D
- Filament PLA
- Fichiers STL du robot Otto-MKS

## Pièces à imprimer
Toutes les pièces du robot ont été imprimées en PLA :

| Pièce | Quantité |
|-------|----------|
| Head (tête/casque requin) | 1 |
| Body (corps requin) | 1 |
| Leg (jambe) | 2 |
| Foot (pied) | 2 |
| Bras | 2 |
| Pelle | 1 |

{: .warning }
> Vérifiez que toutes les pièces s'assemblent correctement 
> avant de passer à l'étape suivante.
