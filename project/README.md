# Les ressources du projet

Ce dossier contient l'ensemble des fichiers sources de notre robot Otto-MKS.

## Contenu

- **Code Arduino** : le programme complet du robot (déplacement, 
  RemoteXY, mode autonome, gestion des bras)
- **Fichier Onshape** : le modèle 3D de notre robot personnalisé 
  (casque requin, body, bras, pelle)
